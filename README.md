# ☕ KofCoffee - Website de Cafeteria


Website responsivo para a cafeteria **KofCoffee**, desenvolvido com HTML5, CSS3 e JavaScript Vanilla. Um projeto que combina design moderno, interatividade e uma experiência acolhedora de café.

## ✨ Funcionalidades
- **Design Responsivo** - Adaptável a todos os dispositivos
- **Navegação Suave** - Scroll animado para seções
- **Cardápio Interativo** - Apresentação visual dos produtos
- **Seção de Depoimentos** - Avaliações de clientes reais
- **Mapa de Localização** - Integração com Google Maps
- **Animações CSS** - Efeitos visuais ao rolar a página

## 🎨 Design
- **Tipografia**: 
  - `Poppins` (moderna)
  - `Josefin Sans` (elegante) 
  - `Great Vibes` (destaques)
- **Ícones**: Font Awesome para elementos visuais


## 🔍 Destaques do Código
- **Navbar fixa** que muda ao scroll
- **Animações** com `data-anime` attributes
- **Layout Grid/Flexbox** para organização responsiva
- **Media Queries** para todos os tamanhos de tela
